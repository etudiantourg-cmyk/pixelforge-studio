PIXELFORGE STUDIO — نسخة الاستضافة

التشغيل على Render:
Runtime: Node
Build command: npm install
Start command: npm start
Region: Frankfurt
Plan: Free للتجربة.

متغيرات البيئة:
ADMIN_PASSWORD: رمز الإدارة السري.
FAL_KEY: لا تضعه في GitHub؛ أدخله من صفحة إعدادات التطبيق بعد تسجيل رمز الإدارة.

الحماية:
مسارات API محمية برمز الإدارة باستثناء فحص الصحة وتنزيل الملفات الناتجة من نطاقات fal الموثوقة.
مفتاح fal لا يعاد للمتصفح، لكنه يبقى في ذاكرة الخادم فقط وقد يلزم إدخاله مجدداً بعد إعادة التشغيل.

التكلفة:
عمليات توليد الصور والفيديو عبر fal قد تستهلك رصيداً مدفوعاً.
